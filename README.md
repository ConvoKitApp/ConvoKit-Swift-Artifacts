# ConvoKit Swift artifacts

Public immutable XCFramework archives for [ConvoKit-Swift-Package](https://github.com/ConvoKitApp/ConvoKit-Swift-Package).

The artifacts are mirrored to [convokit.app/artifacts/swift](https://convokit.app/artifacts/swift/) by the release workflow. They are small static files, so distribution does not require R2.

Do not rewrite an existing version. SDK release automation publishes a new version directory and updates the package checksum.
